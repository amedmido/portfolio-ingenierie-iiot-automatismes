🚀 Projets et Démonstrateurs Industriels
1. Passerelle Edge IIoT et Télémétrie Industrielle (ESP32 / MQTT)
Passerelle d'acquisition de grandeurs critiques sur microcontrôleur ESP32 avec sérialisation de trames JSON, publication télémétrique vers un broker MQTT Cloud et mécanisme de reconnexion automatique.

Technologies : ESP32, C/C++, MQTT, HiveMQ, Protocole JSON, Wi-Fi.

Dépôt GitHub : https://github.com/amedmido/passerelle-edge-iiot-esp32-maquette

Simulation Wokwi : https://wokwi.com/projects/480035239852906497

2. Surveillance Prédictive et Analyse Vibratoire de Moteur (Condition Monitoring)
Banc d'essai de maintenance prédictive pour moteur électrique basé sur Arduino Uno. Analyse continue des vibrations triaxiales (accéléromètre I2C) et de la température pour anticiper les pannes mécaniques.

Technologies : Arduino Uno, MPU6050, DHT22, Bus I2C, Écran LCD 16x2.

Dépôt GitHub : https://github.com/amedmido/banc-surveillance-vibratoire-moteur-industriel

Simulation Wokwi : https://wokwi.com/projects/480033720169224193

3. Système d'Alerte Edge et Sûreté de Fonctionnement Industrielle
Système de détection de seuils critiques avec actionneur relais à verrouillage matériel (Safety Latch) et réarmement physique obligatoire par opérateur selon les normes de sûreté machine.

Technologies : Arduino Uno, Relais de puissance, Capteur industriel, Buzzer, Safety Latch.

Dépôt GitHub : https://github.com/amedmido/systeme-alerte-edge-securite-industrielle

Simulation Wokwi : https://wokwi.com/projects/480030999557788673

4. Contrôle Qualité et Détection de Défauts par Vision Industrielle (AOI)
Module d'inspection optique automatisée (AOI) pour chaînes de production. Traitement d'images numériques pour le filtrage, la segmentation adaptative et la classification des anomalies dimensionnelles en temps réel.

Technologies : Python 3, OpenCV, NumPy, Matplotlib, Google Colab / Edge AI.

Dépôt GitHub : https://github.com/amedmido/controle-qualite-vision-industrielle-opencv

Démonstrateur Colab : https://colab.research.google.com
